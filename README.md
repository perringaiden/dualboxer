# Dual Boxer
A small personal set of tools for managing a following character in World of Warcraft.

# Commands
Command Handler: `/dbr, /dualboxer <command> <parameters>`

* `reset` - Disabled
* `addinviter <character>` - Adds an inviter to the list.
* `inviters` - Lists existing inviters
* `follower` - Sets the character to follower mode.
* `leader` - Sets the character to leader mode.
* `debug` - Enables DEBUG mode.
